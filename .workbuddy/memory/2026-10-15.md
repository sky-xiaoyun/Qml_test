- 讲了：
  - Controls 2 控件 = 预装组件，内部结构可拆：background（底板）/ contentItem（内容）/ 专属零件（indicator、handle、track）。
  - 定制两条路：轻度（palette/font/flat，Material/Universal 下 palette 最可靠，Basic 下部分角色不生效）+ 重度（整体赋值替换 background/contentItem）。

  - 嵌套 parent 陷阱：赋值件的 parent 是控件，赋值件内部的元素 parent 是赋值件——深一层必须用 id 引用（demo CheckBox 实证）。
  - 主题切换：qputenv("QT_QUICK_CONTROLS_STYLE", "material")，Basic/Material/Universal/Imagine 四套；定制控件不受主题影响。
